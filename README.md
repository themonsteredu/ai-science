# 솔로몬 법정 · AI 과학수사 체험

더몬스터학원 · AI 과학수사 교실에서 쓰는 **단일 파일 웹 체험 앱**입니다.
설치 없이 브라우저에서 바로 실행되고, 이미지가 파일 안에 모두 들어 있어 **인터넷 없이도 동작**합니다.

## 사건

재판을 하루 앞둔 밤, 솔로몬 법정에서 핵심 증거인 **USB**가 사라졌다.
그날 밤 법정에 있었던 사람은 단 네 명 — 범인은 이 안에 있다.

## 체험 흐름

| 단계 | 내용 |
|---|---|
| 🎬 오프닝 | 사건 개요 시네마틱 브리핑 |
| 1. 현장 조사 | 오브젝트를 클릭해 단서 7개 수집 |
| 2. 과학 수사 | 감식 4종 — 필적 · 혈액형 · DNA · 지문. 증거물을 **확대해 직접 관찰하고 판정** |
| 3. AI 분석 | 심문으로 모순 찾기 → **직접 진범 지목** → 기소장 작성 → 금고 암호 |
| 4. 모의 재판 | 증거능력 심사 + 법정 상식 퀴즈 |
| 5. 최종 보고 | 수사 결과 및 배운 내용 정리 |

단계 사이는 **교사가 열어줘야** 넘어갑니다 (아래 *수업 운영* 참고).

## 배우는 것

- 감이 아니라 **증거**로 판단하기 (현장에 있었다고 다 범인은 아니다)
- 지문 감식의 실제 절차 — 채취 → 문양 분류 → 특징점 대조
- 증거 하나로는 범인을 정할 수 없다 — **교차 분석으로 좁혀나가기**
- **증거재판주의** · **위법수집증거 배제** · **영장주의** · **무죄추정의 원칙**

## 실행 방법

- **온라인**: 배포 주소로 접속
- **오프라인**: `index.html` 파일을 받아 더블클릭 (USB·카톡으로 전달해도 그대로 동작)

## 수업 운영

### 진도 제어 — 교사가 단계를 열어줍니다

```
현장 조사 ──①── 과학 수사 ──②── AI 분석·기소장·금고 ──③── 모의 재판·최종 보고
```

아이들이 제 속도로 끝까지 달려가지 않도록, 다음 단계는 교사가 열어야 진입됩니다.
상단 단계 탭을 눌러 건너뛰는 것도 함께 막힙니다.

**온라인 (권장)** — 로그인 화면 맨 아래 **🧑‍🏫 선생님이신가요? — 교사 로그인** 으로 들어갑니다.
수업코드와 교사 PIN으로 로그인하면 진도 패널이 열리고, 단계 버튼을 누르면 같은 수업코드로 접속한
**모든 학생 화면이 15초 안에 함께 열립니다.** 로그인 후에는 왼쪽 아래 **🧑‍🏫 진도 열기** 버튼이 남아
수업 중 언제든 다시 열 수 있고, "이 기기에 기억하기" 를 켜면 다음 수업부터 바로 들어갑니다.

PIN은 서버(`TEACHER_PIN`)에만 있으므로 **입구를 숨길 필요가 없습니다** — 아이가 교사 로그인 창을
열어봐도 PIN 없이는 아무것도 열지 못합니다. (주소에 `?t=1` 을 붙이는 지름길도 그대로 동작합니다.)

**오프라인** — 서버에 연결할 수 없으면 로그인은 통과되고, 단계 버튼을 누를 때 PIN 칸의 값을
**단계별 해제 암호**로 확인해 **그 기기만** 엽니다. 암호는 `교사용-정답지.md` 에 있습니다.
HTML 안에 해시로 들어 있어 소스를 훑어보는 정도로는 안 보이지만 작정하고 찾으면 뚫리므로,
인터넷이 되는 교실에서는 서버 방식을 쓰세요.

로그인에서 **"코드 없이 혼자 연습하기"** 로 들어오면 잠금이 걸리지 않습니다.

### 정답지

**[`교사용-정답지.md`](교사용-정답지.md)** — 단계별 전체 정답, 기소장 모범 답안, 오프라인 해제 암호,
그리고 *현장 조사가 끝나면 무고한 박철웅이 의심도 1위가 되는 의도적 함정* 같은 운영 주의사항.

> ⚠️ 이 문서는 아이들과 공유하지 마세요.

## 서버 설정 (Vercel)

순위판과 진도 제어를 쓰려면 두 가지가 필요합니다.

| 항목 | 설정 |
|---|---|
| DB | Vercel Marketplace에서 **Upstash Redis** 연결 (`UPSTASH_REDIS_REST_URL` / `_TOKEN` 자동 주입) |
| 교사 PIN | 환경변수 **`TEACHER_PIN`** 에 원하는 값 설정 |

`TEACHER_PIN` 은 **서버에만** 있어서 학생이 HTML 소스를 봐도 알 수 없습니다.
설정하지 않으면 서버 방식으로 단계를 열 수 없습니다(오프라인 암호는 그대로 동작).

### 설정 확인 — `/api/gate?diag=1`

배포 주소 뒤에 **`/api/gate?diag=1`** 을 붙여 열면 무엇이 빠졌는지 알려줍니다 (값은 절대 노출하지 않고 이름만).

```json
{ "db": true, "teacherPin": true, "found": ["UPSTASH_REDIS_REST_URL", "..."], "hint": "정상입니다." }
```

| 증상 | 뜻 | 조치 |
|---|---|---|
| `db: false`, `found: []` | Redis 미연결 | Upstash Redis 연결 후 **재배포** |
| `db: false`, `found: ["REDIS_URL"]` | Redis 는 있지만 REST 주소·토큰이 없음 | Upstash 통합에서 REST API 변수를 노출하도록 다시 연결 |
| `db: true`, `teacherPin: false` | PIN 미설정 | `TEACHER_PIN` 설정 후 **재배포** |

> **DB 가 없으면 PIN 이 맞아도 거부됩니다.** `api/gate.js` 가 DB 확인을 PIN 확인보다 먼저 하기 때문입니다.
> 이때 교사 창은 "DB 가 연결되지 않았다"고 알려주고, 오프라인 암호로 기기별 해제만 가능합니다.
>
> 환경변수는 **빌드 시점에 주입**되므로 등록만 하고 재배포하지 않으면 적용되지 않습니다.

DB를 연결하지 않으면 순위판과 서버 진도 제어만 비활성화되고, 수업 자체는 그대로 진행됩니다.

| API | 용도 |
|---|---|
| `GET/POST /api/results` | 수업코드별 결과 저장·조회 (순위판) |
| `GET /api/gate?code=…` | 열린 단계 조회 (학생이 폴링) |
| `POST /api/gate` | 단계 설정 — **교사 PIN 필요** |

> ⚠️ `/api/results` 에는 인증이 없습니다. 수업코드만 알면 누구나 반 전체 결과를 읽고 덮어쓸 수 있고,
> 저장 내용에 아이가 쓴 수첩 메모와 기소장 서술이 포함됩니다. 수업코드를 외부에 공유하지 마세요.

## 기술

- 의존성 없는 단일 HTML 파일 (약 1.5MB)
- 외부 라이브러리 없음. 증거물 이미지는 모두 base64로 내장 — 인터넷 없이도 그대로 보입니다
- 네트워크를 쓰는 곳은 순위판(`/api/results`)과 진도 제어(`/api/gate`) 두 곳뿐이고, 없어도 동작합니다
- 모바일·데스크톱 반응형 (스크롤하면 헤더가 접혀 증거물 볼 공간이 넓어집니다)
